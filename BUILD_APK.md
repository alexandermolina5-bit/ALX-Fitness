# Compilación de ALX Fitness 5.3

El proyecto incluye `.github/workflows/android-build.yml`. Al subir la carpeta completa a GitHub, la acción compila automáticamente:

- `app-debug.apk`, instalable para pruebas.
- `app-release.aab`, preparado para el proceso de firma y publicación.

En GitHub: abre **Actions**, selecciona **Compilar ALX Fitness**, pulsa **Run workflow** y descarga los archivos desde **Artifacts** cuando finalice.

También puede abrirse en Android Studio con Java 17 y Android SDK 35.
