# Mejoras incluidas en ALX Fitness 4.0

- Proyecto fuente Android editable y listo para compilar.
- 15 rutinas completas con ejercicios individuales.
- Rutinas de cuerpo completo para principiante, intermedio y avanzado.
- Pecho con flexión clásica, abierta, cerrada, diamante, inclinada y declinada.
- Desafío de planchas con seis variantes.
- Entrenamientos para hombros, bíceps, tríceps, espalda, abdomen, piernas y glúteos.
- Cardio de nivel principiante, intermedio y avanzado.
- Opciones sin equipo, con mancuernas y con bandas.
- Calentamiento y estiramiento integrados en el plan inicial.
- Plan nutricional de siete días con selector para aumentar masa muscular o perder grasa.
- Calendario semanal con recomendación de días según el nivel y casillas de seguimiento.
- Recuadro del avatar ampliado a 330 dp durante el entrenamiento.

## Animaciones

El proyecto conserva el avatar incluido como visual de respaldo. Los GIF individuales no se inventaron ni duplicaron: deben añadirse como recursos cuando se disponga de una animación correcta para cada ejercicio.

## Compilación

Usa Android Studio o el flujo de GitHub Actions incluido. El proyecto está configurado como versión 4.0 (`versionCode 4`).
